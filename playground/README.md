# Playground

Interactive docs for **useThisHook** (npm: `usethishook`). The home page explains the library and how to install it. Each hook page shows a live component, the API, and copy-paste example code.

From the repository root:

```bash
npm install
npm run playground
```

Then open the URL Vite prints (usually `http://localhost:5173`).

- Home (`/`): what it is, benefits, install, hook index
- Hook pages (`/useBoolean`, `/useOverlay`, …): preview + API + example

Legacy hash URLs (`#/useBoolean`) redirect to path routes in the browser.

Build a static site with `npm run playground:build` (output in `playground/dist`). That build uses `base: /` for Vercel and the custom domain `https://usethishook.mentorbridge.in`.

GitHub Pages is a project site at `/useThisHook/`. The Pages build sets Vite `base` to `/useThisHook/` and copies `index.html` to `404.html` so deep links reload the SPA (GitHub Pages serves `404.html` for unknown paths). CI runs `npm run playground:build:pages` and deploys `playground/dist` via [`.github/workflows/pages.yml`](../.github/workflows/pages.yml).

SEO assets (`robots.txt`, `sitemap.xml`) are generated by `npm run playground:seo` before each playground build.

The playground defaults to light mode. Theme choice is stored in `localStorage` under `usethishook-theme`.
